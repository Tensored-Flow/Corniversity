# Meridian University — Codex Build Pack

This pack specifies a personal university to be implemented. It does not contain an already-built website or deployed application.

## Files

- `UNIVERSITY_BUILD_BRIEF.md`: the complete implementation prompt, product design, academic model, architecture, workflows, acceptance tests, and appendices. This is authoritative.
- `START_HERE.txt`: the launcher prompt to paste into desktop Codex after the pack is accessible in the project workspace.
- `VERIFIED_SOURCES.md`: primary-source starting points, what was actually checked, and what still needs verification.
- `COURSE_CATALOGUE_SEED.json`: machine-readable desired catalogue. Entries are proposed course concepts, not completed teaching content or verified prerequisites.

## Use

Create a new dedicated project folder, such as `C:\Users\<you>\Projects\meridian-university`. Extract these files there and open that project in Codex. Do not use the Downloads directory itself as the project root or mix this into Kalibr.

Paste the contents of `START_HERE.txt` into Codex. Keep the master brief available as a file; Codex should read all of it rather than relying only on the launcher.

Leave ordinary approval and sandbox controls enabled. Provider keys, private deployment access, and any spending authorization remain yours to configure. The brief directs Codex to finish independent work and identify the exact minimal remaining actions rather than pretending unavailable integrations work.

The working name Meridian and all academic/persona structures are configurable. No real university affiliation, accreditation, existing grades, or completed coursework is implied.
