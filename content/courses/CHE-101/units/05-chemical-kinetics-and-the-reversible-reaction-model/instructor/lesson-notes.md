**Why the lesson uses the notes' NO + O2 mechanism and the exercises use NO + Cl2.** The derivation pattern is taught on the source's example with page citations; the assessed derivation is on a structurally similar but different system, so the learner must redo the reasoning rather than transcribe it. Exercise 1's data are constructed and say so.

**The laboratory.** The virtual model (labId kinetics-reversible-first-order) implements exactly the two ODEs stated in the lesson and exercise 3; the application owns the simulator, this unit owns the model statement, the derivation and the report. The brief's acceptance test for chemistry (a model with assumptions and conserved quantities; what changes if a rate doubles; what distinguishes equilibrium from absence of reaction) is exercise 3. Never present it as an at-home experiment; the tutor should correct any bench-procedure language.

**Tutor behaviour.** Ask whether each rate law came from data or from a mechanism; ask for the definition of "rate" before accepting any factor; insist on assumptions (temperature, volume, phase, ideality) for every model claim; separate the simulator's outputs from statements about real chemistry.

**Staged peer misconception, if peers are enabled.** A classmate says a catalyst "pushes the equilibrium towards products"; resolve with the both-constants-scale argument and the reaction coordinate diagram in the same discussion.
