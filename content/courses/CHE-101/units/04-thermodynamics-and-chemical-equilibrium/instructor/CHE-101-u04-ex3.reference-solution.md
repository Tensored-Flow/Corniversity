## Reference reasoning (instructor only)

Reaction as written: $\ce{N2O4(g) <=> 2 NO2(g)}$, $K = 0.146$ at 298 K, pressures in bar relative to $P^\circ = 1$ bar. (Lecture 18, page 3, uses $K = 6.84$ for $\ce{2 NO2 <=> N2O4}$ at 298 K; $1/6.84 = 0.146$.)

**1. $Q$.** $Q = P(\ce{NO2})^2/P(\ce{N2O4}) = 0.100^2/0.500 = 0.0200$. $Q < K$, so $\Delta G = RT\ln(Q/K) < 0$ and the forward reaction runs: $\ce{N2O4}$ dissociates until $Q = K$.

**2. ICE table.** Initial: $\ce{N2O4}$ 1.000, $\ce{NO2}$ 0. Change: $-x$, $+2x$. Equilibrium: $1.000 - x$, $2x$. $K = (2x)^2/(1.000 - x) = 0.146 \Rightarrow 4x^2 + 0.146x - 0.146 = 0 \Rightarrow x = \dfrac{-0.146 + \sqrt{0.146^2 + 4(4)(0.146)}}{8} = \dfrac{-0.146 + 1.5354}{8} = 0.1737$ bar. So $P(\ce{NO2}) = 0.347$ bar and $P(\ce{N2O4}) = 0.826$ bar. Check: $0.347^2/0.826 = 0.1206/0.826 = 0.146$.

**3. $\Delta G^\circ$.** $\Delta G^\circ = -RT\ln K = -(8.314)(298)\ln(0.146) = -(2477.6)(-1.924) = +4770$ J/mol $= +4.77$ kJ/mol. Positive because $K < 1$: reactants are favoured under standard conditions, yet the reaction proceeds to a substantial equilibrium extent from pure $\ce{N2O4}$, as part 2 shows.

**4. Stresses.** (a) Halving the volume at constant $T$ doubles every partial pressure; $Q$ becomes $(2\cdot2x)^2/(2(1-x)) = 2Q_{\text{eq}} > K$, so the system shifts to the side with fewer moles of gas ($\ce{N2O4}$) and the amount of $\ce{NO2}$ falls; $K$ unchanged. (b) The forward reaction is endothermic, so raising $T$ raises $K$ (van 't Hoff with $\Delta H^\circ > 0$); more $\ce{NO2}$ at the new equilibrium. (c) Argon at constant volume changes no partial pressure of $\ce{NO2}$ or $\ce{N2O4}$, so $Q$ is unchanged: no shift, $K$ unchanged. (d) A catalyst lowers the barrier for both directions equally; neither $Q$ nor $K$ changes, equilibrium is only reached sooner.

**Alternative valid approaches.** Solving the ICE problem in moles with $PV = nRT$; using the lecture's value $6.84$ for the reverse reaction consistently (then $\Delta G^\circ$ for the reverse is $-4.77$ kJ/mol, and the learner must say which reaction they mean). Accept $P(\ce{NO2}) = 0.347$–$0.348$ bar and $\Delta G^\circ = 4.76$–$4.78$ kJ/mol.

**Common gaps.** Using $x$ instead of $2x$ for $\ce{NO2}$; dropping the square; reporting $Q = 0.2$ (forgetting the square); claiming $K$ changes with pressure or that argon shifts the equilibrium because "pressure increases" (total pressure does, partial pressures do not); saying a catalyst increases the yield.
