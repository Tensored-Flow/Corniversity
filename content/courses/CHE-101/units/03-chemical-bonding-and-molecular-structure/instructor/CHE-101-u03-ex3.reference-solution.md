## Reference reasoning (instructor only)

Ordering used (for $\ce{O2}$, $\ce{F2}$ and their ions): $\sigma_{2s} < \sigma^*_{2s} < \sigma_{2p} < \pi_{2p}\,(\times2) < \pi^*_{2p}\,(\times2) < \sigma^*_{2p}$.

**1. $\ce{O2}$, 12 valence electrons.** $(\sigma_{2s})^2(\sigma^*_{2s})^2(\sigma_{2p})^2(\pi_{2p})^4(\pi^*_{2p})^2$. Bonding electrons: $2 + 2 + 4 = 8$; antibonding: $2 + 2 = 4$; bond order $\tfrac12(8 - 4) = 2$. By Hund's rule the two $\pi^*$ electrons occupy the two degenerate $\pi^*$ orbitals singly with parallel spins: two unpaired electrons, paramagnetic.

**2. The ions.** $\ce{O2^+}$ (11 electrons): $(\pi^*_{2p})^1$, bond order $\tfrac12(8 - 3) = 2.5$, one unpaired electron. $\ce{O2^-}$ (13 electrons): $(\pi^*_{2p})^3$, bond order $\tfrac12(8 - 5) = 1.5$, one unpaired electron. Removing an antibonding electron strengthens and shortens the bond; adding one weakens and lengthens it. Bond length: $\ce{O2^+} < \ce{O2} < \ce{O2^-}$. (Measured bond lengths follow this order; the exercise asks for the prediction, not the values.)

**3. Where Lewis fails.** $\ce{O=O}$ has two bonding pairs and two lone pairs on each oxygen, all electrons paired, which predicts a diamagnetic molecule (weakly repelled by a magnetic field). Liquid oxygen is observed to be paramagnetic, attracted into a magnetic field, so the molecule has unpaired electrons. MO theory gets the bond order 2 right and also the two unpaired electrons, because the highest occupied level is a degenerate pair of $\pi^*$ orbitals filled by Hund's rule. Lewis structures have no way to express degeneracy.

**4. Meaning of bond order.** Bond order is the net number of bonding electron pairs, bonding minus antibonding over two; it tracks bond strength and inverse bond length. A fractional value describes an odd number of net bonding electrons, five for $\ce{O2^+}$; nothing requires electrons to come in bonding pairs.

**Alternative valid approaches.** Using the alternative ordering ($\pi_{2p}$ below $\sigma_{2p}$, correct for $\ce{B2}$ to $\ce{N2}$) changes which bonding orbitals are filled but not the bond orders or the unpaired-electron counts for these species; accept with a note that the prompt specified the heavier-diatomic ordering.

**Common gaps.** Counting all 16 electrons and forgetting to cancel the $1s$ pairs (fine if done consistently); giving $\ce{O2^+}$ bond order 3 by "removing an antibonding electron adds a bond"; declaring $\ce{O2}$ diamagnetic from the Lewis structure; reversing the length ranking.
