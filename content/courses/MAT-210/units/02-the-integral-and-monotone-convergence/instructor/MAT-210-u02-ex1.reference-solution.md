## Reference reasoning (instructor only)

Throughout, $X=\mathbb N$, $\mathcal M=\mathcal P(\mathbb N)$, $\mu$ = counting measure; every function on $\mathbb N$ is measurable, and $\mu(\{k\})=1$.

**1. The integral is the sum.** Write $S=\sum_{k\ge1}f(k)\in[0,\infty]$.

*Case: some $f(k_0)=\infty$.* Then $S=\infty$. For every $m\in\mathbb N$ the simple function $s=m\chi_{\{k_0\}}$ satisfies $0\le s\le f$ and $\int s\,d\mu=m\,\mu(\{k_0\})=m$, so $\int f\,d\mu\ge m$ for all $m$: $\int f\,d\mu=\infty=S$.

*Case: $f$ finite-valued.* Lower bound: for each $N$ let $s_N=f\chi_{\{1,\dots,N\}}$. It takes finitely many finite values, so it is simple, $0\le s_N\le f$, and $\int s_N\,d\mu=\sum_{k\le N}f(k)\,\mu(\{k\})=\sum_{k\le N}f(k)$ (the disjoint representation by the singletons $\{1\},\dots,\{N\}$ plus the value $0$ on the rest). Hence $\int f\,d\mu\ge\sup_N\sum_{k\le N}f(k)=S$.

Upper bound: let $0\le s\le f$ be simple, $s=\sum_i\alpha_i\chi_{A_i}$ with disjoint $A_i$ and distinct values $\alpha_i$. If some $\alpha_i>0$ has $A_i$ infinite, then $S\ge\sum_{k\in A_i}f(k)\ge\sum_{k\in A_i}\alpha_i=\infty$ and there is nothing to prove. Otherwise every $A_i$ with $\alpha_i>0$ is finite and
$$\int s\,d\mu=\sum_i\alpha_i\,\#A_i=\sum_i\sum_{k\in A_i}s(k)=\sum_ks(k)\le\sum_kf(k)=S .$$
Taking the supremum over $s$, $\int f\,d\mu\le S$. $\square$

**2. Double series.** Define $f_j:\mathbb N\to[0,\infty]$ by $f_j(i)=a_{ij}$. Theorem 0.3 of lecture 4 gives $\int\sum_jf_j\,d\mu=\sum_j\int f_j\,d\mu$. By part 1 the left side is $\sum_i\big(\sum_jf_j(i)\big)=\sum_i\sum_ja_{ij}$ and the right side is $\sum_j\sum_if_j(i)=\sum_j\sum_ia_{ij}$. (This is Corollary 0.4 of lecture 4; the exercise supplies the step the notes leave implicit.)

**3. Moving bumps.** Take $f_n=\chi_{\{n\}}$. For fixed $k$, $f_n(k)=0$ once $n>k$, so $f_n\to0$ pointwise; $\int f_n\,d\mu=\mu(\{n\})=1$. The sequence is not increasing ($f_n(n)=1>0=f_{n+1}(n)$), so the monotone convergence theorem does not apply, and indeed $\int f_n=1\not\to0=\int\lim f_n$. Fatou: $\int\liminf f_n=\int0=0\le1=\liminf\int f_n$, a strict inequality.

**Alternative valid approaches.** Part 1 may be organised as "for finite-valued $f$ the truncations increase to $f$, so $\int f=\lim\int s_N$ by monotone convergence" — correct and shorter, but the exercise asks for the argument from the definition; accept it with a note, since it still needs $\int s_N=\sum_{k\le N}f(k)$ and the MCT is proved in this unit. Other valid bump sequences: $f_n=\frac1n\chi_{\{1,\dots,n\}}$ (pointwise limit $0$, integral $1$), or $f_n=\chi_{\{n,\dots,2n-1\}}/n$.

**Common gaps.** Treating $s=f\chi_{\{1..N\}}$ as simple when $f$ takes the value $\infty$; forgetting that a simple function may carry a positive value on an infinite set (so $\int s=\infty$) and that this case must be reconciled with $S=\infty$; in part 3 claiming the failing hypothesis is "integrability" or "domination" rather than monotonicity (domination is unit 3's language; if used correctly, accept with a note that it is not yet available).
