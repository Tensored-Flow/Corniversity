## Reference reasoning (instructor only)

**1. Direct computation.** Write $\Phi \equiv dF/dt = F_q\dot q + F_t$ (subscripts denote partial derivatives). Then
$$\frac{\partial\Phi}{\partial\dot q} = F_q,\qquad \frac{d}{dt}\frac{\partial\Phi}{\partial\dot q} = F_{qq}\dot q + F_{qt},\qquad \frac{\partial\Phi}{\partial q} = F_{qq}\dot q + F_{tq}.$$
Because $F$ is $C^2$, $F_{qt} = F_{tq}$, so $\frac{d}{dt}\frac{\partial\Phi}{\partial\dot q} - \frac{\partial\Phi}{\partial q} = 0$. The Euler–Lagrange expression is linear in $L$, so $L$ and $L + \Phi$ have identical Euler–Lagrange equations.

*One-line action argument.* $S' = S + \int_{t_1}^{t_2}\frac{dF}{dt}dt = S + F(q(t_2),t_2) - F(q(t_1),t_1)$. Under variations with fixed endpoints the added term is constant, so $\delta S' = \delta S$ and the stationary paths coincide.

**2. The three Lagrangians.** $c\,x\dot x = \frac{d}{dt}\big(\tfrac12 c x^2\big)$, so $L_2 = L_1 + dF/dt$ with $F = \tfrac12 c x^2$: same motion ($m\ddot x = 0$). Check directly: $\partial L_2/\partial\dot x = m\dot x + cx$, $\frac{d}{dt}(\cdot) = m\ddot x + c\dot x$, $\partial L_2/\partial x = c\dot x$, difference $m\ddot x = 0$. Units: $c\,x\dot x$ must be joules, so $[c] = \mathrm{J\,s\,m^{-2}} = \mathrm{kg\,s^{-1}}$.

$L_3$: $\frac{d}{dt}(m\dot x) - 2cx = 0$, i.e. $m\ddot x = 2cx$: exponential growth/decay for $c>0$, harmonic oscillation for $c<0$. Not the free particle. (Equivalently: $cx^2$ is not a total time derivative of any $F(x,t)$ — it has no $\dot x$ and is not of the form $F_t$ with $F_x = 0$ unless it is independent of $x$.) Units: $[c] = \mathrm{J\,m^{-2}} = \mathrm{kg\,s^{-2}} = \mathrm{N\,m^{-1}}$.

**3. Other alterations.** $\lambda L$: the Euler–Lagrange expression scales by $\lambda\neq 0$, so the equation $\lambda(\dots) = 0$ is equivalent. $L + \text{const}$: the constant has zero derivatives. $L + G(q)$: the Euler–Lagrange expression gains $-G'(q)$, i.e. a force $G'(q)$ is added; harmless only if $G' \equiv 0$. (The $\lambda$ case is the notes' scaling-symmetry remark in Section 1.3; the $G(q)$ case is exactly what distinguishes $L_3$ from $L_1$.)

**Alternative valid approaches.** A learner may prove part 1 for $N$ degrees of freedom at once; or argue via the action only, provided the fixed-endpoint condition is stated. Accept "$L_3$ is a harmonic oscillator or an inverted oscillator depending on the sign of $c$" as the demonstration that it differs from $L_1$.

**Common gaps.** Omitting the role of equality of mixed partials; forgetting that the endpoints must be fixed for the boundary term to be constant; asserting "$L_3$ differs from $L_1$ by a function of $x$ only, so it is equivalent" (this is the targeted misconception, and the automatic check `l3-not-free` flags it); wrong units for $c$.
