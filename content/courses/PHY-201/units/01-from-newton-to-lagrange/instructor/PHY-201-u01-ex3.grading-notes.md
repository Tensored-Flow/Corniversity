## Grading notes (instructor only)

This is an explanation exercise; grade the ideas, not the prose, and keep feedback under 120 words.

- (a) Must contain: the Euler–Lagrange equations have the same form in every coordinate system (covariance under point transformations), so terms such as the centripetal $m r\dot\theta^2$ appear automatically instead of having to be derived from the acceleration vector. Bonus, not required: the action is a coordinate-independent number.
- (b) Must contain: holonomic constraints are handled by choosing independent coordinates, so the forces of constraint are never computed. Expect the qualification that the constraint must be frictionless (do no virtual work); if it is missing, ask for it rather than marking down heavily — unit 2 makes it precise.
- Non-potential force: friction or drag (velocity-dependent, not derivable from a potential) is the expected answer. Accommodation: add generalized forces $Q_j$ to the right-hand side of the Euler–Lagrange equations, equivalently start from D'Alembert's principle (unit 2); a Rayleigh dissipation function is also acceptable. The Lorentz force is *not* a correct example of a force the formalism cannot handle (it has a generalized potential); if offered, say so briefly.
- Route to `needs_review` only if the learner argues that Hamilton's principle is a minimum principle in general; otherwise this exercise is low-stakes.
