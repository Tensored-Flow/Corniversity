## Reference reasoning (instructor only)

**1. The bound.** Call $h\in H$ *bad* if $\mathrm{err}(h)>\varepsilon$. Fix a bad $h$. For one example $x\sim D$, $\Pr[h(x)=c(x)]=1-\mathrm{err}(h)<1-\varepsilon$. Because the $N$ examples are drawn *independently* from $D$, the probability that $h$ agrees with $c$ on all of them is less than $(1-\varepsilon)^N\le e^{-\varepsilon N}$ (using $1-\varepsilon\le e^{-\varepsilon}$). There are at most $|H|$ bad hypotheses, so by the union bound
$$\Pr[\text{some bad } h \text{ is consistent with the sample}]<|H|\,e^{-\varepsilon N}.$$
This is at most $\delta$ exactly when $e^{-\varepsilon N}\le\delta/|H|$, i.e. $N\ge\frac1\varepsilon\big(\ln|H|+\ln\frac1\delta\big)$. On the complementary event (probability $\ge1-\delta$) every consistent hypothesis has error at most $\varepsilon$.

Where the assumptions enter: independence is used to multiply the per-example probabilities; the identity of the training distribution and the distribution defining $\mathrm{err}$ is used when $\Pr[h(x)=c(x)]$ for a training example is equated with $1-\mathrm{err}(h)$. Without the latter the bound says nothing about future performance.

**2. Counting.** Conjunctions over $k$ features: each feature is required true, required false, or absent, independently, so $|H|=3^k$ and $\ln|H|=k\ln3$. (Whether one also counts the empty/contradictory concept changes $|H|$ by one and is irrelevant.) All Boolean concepts: there are $2^k$ objects and each can be labelled in or out independently, so $|H|=2^{2^k}$ and $\ln|H|=2^k\ln2$.

**3. Numbers** ($\varepsilon=0.1$, $\delta=0.05$, $k=10$; $\ln3=1.09861$, $\ln2=0.693147$, $\ln20=2.99573$):

- Conjunctions: $N\ge10\,(10\times1.09861+2.99573)=10\times13.9818=139.82$, so $N\ge140$.
- All Boolean concepts: $N\ge10\,(1024\times0.693147+2.99573)=10\times712.778=7127.8$, so $N\ge7128$.

**4. Interpretation.** With the same error and confidence targets, restricting the learner to conjunctions makes learning from about 140 examples provably safe, whereas an unrestricted learner would need more examples than there are objects ($2^{10}=1024$) to be guaranteed anything, because every labelling of the unseen objects remains consistent. The restriction is the inductive bias, and the bound shows there is no learning without it. The assumption no bias removes is that training and future examples are independent draws from the same distribution: the uniformity-of-nature assumption, which the lecture flags as what PAC still requires.

**Alternative valid approaches.** Bounding with $(1-\varepsilon)^N$ directly and solving $|H|(1-\varepsilon)^N\le\delta$ gives $N\ge\frac{\ln|H|+\ln(1/\delta)}{-\ln(1-\varepsilon)}$, slightly smaller ($-\ln0.9=0.10536$, so $132.7\to133$ and $6765.5\to6766$); accept with a note that the exponential form is the standard loose version. Counting conjunctions as $2^k$ "subsets of literals" is wrong unless negations are excluded, in which case say so explicitly (then $|H|=2^k$ and the lesson's count differs; mark as partially met with a precise comment).

**Common gaps.** Omitting the union bound and treating the bad hypothesis as if it were the learner's output; forgetting to name the i.i.d. assumption; counting $2^k$ conjunctions; using $\log_2$ in one place and $\ln$ in another; not rounding up.
