## Reference reasoning (instructor only)

Signature $(-,+,+,+)$, $c = 1$ until part 6.

**1.** $u\cdot u = \eta_{\mu\nu}u^\mu u^\nu = -1$ along the worldline. Differentiating, $2\eta_{\mu\nu}u^\mu\,du^\nu/d\tau = 2\,u\cdot a = 0$.

**2.** Go to the momentary rest frame, where $u^\mu = (1,\mathbf 0)$. Then $u\cdot a = -a^0 = 0$, so $a^\mu = (0,\mathbf a_{\rm rest})$, and $\mathbf a_{\rm rest} = d^2\mathbf x/dt^2$ there (since $d\tau = dt$ to first order at the instant of rest), of magnitude $\alpha$. Hence $a\cdot a = |\mathbf a_{\rm rest}|^2 = \alpha^2 \ge 0$: spacelike (or zero). Being a scalar, $a\cdot a = \alpha^2$ holds in every frame.

**3.** Motion along $x$: $u^\mu = (u^0,u^1,0,0)$ with $(u^0)^2 - (u^1)^2 = 1$, so $u^0 = \cosh\theta$, $u^1 = \sinh\theta$ for some $\theta(\tau)$ (the positive branch, $u^0>0$). Then $a^\mu = \dot\theta(\sinh\theta,\cosh\theta,0,0)$ and $a\cdot a = \dot\theta^2(-\sinh^2\theta + \cosh^2\theta) = \dot\theta^2 = \alpha^2$. With $\theta(0) = 0$ (at rest) and $\dot\theta>0$: $\theta = \alpha\tau$. Integrate $dt/d\tau = \cosh\alpha\tau$, $dx/d\tau = \sinh\alpha\tau$ with $t(0) = x(0) = 0$:
$$t(\tau) = \frac{\sinh\alpha\tau}{\alpha},\qquad x(\tau) = \frac{\cosh\alpha\tau - 1}{\alpha}.$$

**4.** $(x + 1/\alpha)^2 - t^2 = (\cosh^2\alpha\tau - \sinh^2\alpha\tau)/\alpha^2 = 1/\alpha^2$: a hyperbola asymptotic to the light rays through $(t,x) = (0,-1/\alpha)$. $v = dx/dt = (dx/d\tau)/(dt/d\tau) = \tanh\alpha\tau$. Since $v = \tanh\phi$ defines the rapidity, $\phi = \alpha\tau$: proper acceleration is the rate of change of rapidity with respect to proper time, $d\phi/d\tau = \alpha$. (Rapidity adds, so this is also why constant proper acceleration means "the same boost every proper second".)

**5.** $\cosh\alpha\tau - 1 = \tfrac12\alpha^2\tau^2 + \tfrac1{24}\alpha^4\tau^4 + \dots$, so $x = \tfrac12\alpha\tau^2 + \tfrac1{24}\alpha^3\tau^4 + \dots$; and $t = \tau + \tfrac16\alpha^2\tau^3+\dots$, so to leading order $x\approx\tfrac12\alpha t^2$, $v\approx\alpha t$: Newtonian uniform acceleration. The first neglected term in $x(\tau)$ is $\alpha^3\tau^4/24$, relative size $\alpha^2\tau^2/12$.

**6.** Dimensional analysis: $\alpha\tau$ must become $\alpha\tau/c$ (dimensionless), $1/\alpha$ must become $c^2/\alpha$ (a length) in $x$ and $c/\alpha$ (a time) in $t$:
$$x = \frac{c^2}{\alpha}\Big(\cosh\frac{\alpha\tau}{c} - 1\Big),\qquad t = \frac c\alpha\sinh\frac{\alpha\tau}{c},\qquad v = c\tanh\frac{\alpha\tau}{c}.$$
Units: $c^2/\alpha = \mathrm{m^2\,s^{-2}/(m\,s^{-2})} = \mathrm m$; $c/\alpha = \mathrm s$; $v$ in $\mathrm{m\,s^{-1}}$. For $v = 0.9c$: $\alpha\tau/c = \operatorname{artanh}0.9 = \tfrac12\ln\frac{1.9}{0.1} = \tfrac12\ln 19 = 1.472$, so $\tau = 1.472\,c/\alpha = 1.472\times(2.998\times10^8/9.8)\ \mathrm s = 4.50\times10^7\ \mathrm s = 1.43\ \mathrm{yr}$. (Coordinate time $t = (c/\alpha)\sinh 1.472 = 2.065\,c/\alpha = 2.00\ \mathrm{yr}$.)

**Alternative valid approaches.** Solving $du^1/d\tau = \alpha u^0$, $du^0/d\tau = \alpha u^1$ (from $a\cdot a = \alpha^2$ with $a\propto(u^1,u^0)$) as a linear system gives the same result. Working in the lab with $d(\gamma v)/dt = \alpha$ (the rest-frame acceleration transformed) is acceptable if the transformation of acceleration is justified.

**Common gaps.** Dropping the $-1$ in $x(\tau)$ (initial condition); claiming $a$ is timelike; forgetting that $a\cdot a = \alpha^2$ is only *evaluated* in the rest frame but *holds* everywhere; restoring $c$ inconsistently (a common wrong form is $x = (c/\alpha)(\cosh - 1)$, caught by units).
