## Reference reasoning (instructor only)

Signature $(-,+,+,+)$.

**1. Trace.** $T'^{\mu\nu} = \Lambda^\mu{}_\alpha\Lambda^\nu{}_\beta T^{\alpha\beta}$ and $\eta'_{\mu\nu} = \eta_{\mu\nu}$, so $\eta_{\mu\nu}T'^{\mu\nu} = \eta_{\mu\nu}\Lambda^\mu{}_\alpha\Lambda^\nu{}_\beta T^{\alpha\beta} = \eta_{\alpha\beta}T^{\alpha\beta}$ by $\Lambda^T\eta\Lambda = \eta$. Equivalently, lower one index and contract. Counterexample for the plain sum: $T^{\mu\nu} = u^\mu u^\nu$ with $u = (1,0,0,0)$: $\sum_\mu T^{\mu\mu} = 1$. Boost along $x$: $u' = \gamma(1,v,0,0)$, $\sum_\mu T'^{\mu\mu} = \gamma^2 + \gamma^2v^2 = \gamma^2(1+v^2) = \frac{1+v^2}{1-v^2} \ne 1$ for $v\neq0$, whereas $\eta_{\mu\nu}T^{\mu\nu} = u\cdot u = -1$ in both frames. The plain sum treats the time component with the wrong sign; "trace of a matrix is basis independent" applies to a $(1,1)$ tensor (a linear map), not to a $(2,0)$ tensor.

**2. Invariant tensors.** $\delta'^\mu{}_\nu = \Lambda^\mu{}_\alpha(\Lambda^{-1})^\beta{}_\nu\delta^\alpha{}_\beta = \Lambda^\mu{}_\alpha(\Lambda^{-1})^\alpha{}_\nu = \delta^\mu{}_\nu$ — this holds for *any* invertible Jacobian, so $\delta$ is invariant under general coordinate transformations too. $\eta'_{\mu\nu} = (\Lambda^{-1})^\alpha{}_\mu(\Lambda^{-1})^\beta{}_\nu\eta_{\alpha\beta} = \eta_{\mu\nu}$ is exactly the condition $\Lambda^T\eta\Lambda = \eta$ (applied to $\Lambda^{-1}$, which is also Lorentz). Under a general transformation the Jacobian $J^\alpha{}_\mu = \partial x^\alpha/\partial x'^\mu$ need not satisfy $J^T\eta J = \eta$; e.g. plane polar coordinates give $g'_{rr} = 1$, $g'_{\theta\theta} = r^2$, $g'_{r\theta} = 0$. The metric is a tensor, but its *components* are frame independent only for the transformations that preserve them by definition.

**3. Partial derivative of a one-form.** Under Lorentz: $A'_\nu = (\Lambda^{-1})^\beta{}_\nu A_\beta$ and $\partial'_\mu = (\Lambda^{-1})^\alpha{}_\mu\partial_\alpha$ with constant matrices, so $\partial'_\mu A'_\nu = (\Lambda^{-1})^\alpha{}_\mu(\Lambda^{-1})^\beta{}_\nu\partial_\alpha A_\beta$: a $(0,2)$ tensor. Under $x\to x'(x)$: $A'_\nu = \frac{\partial x^\beta}{\partial x'^\nu}A_\beta$, so
$$\partial'_\mu A'_\nu = \frac{\partial x^\alpha}{\partial x'^\mu}\frac{\partial x^\beta}{\partial x'^\nu}\,\partial_\alpha A_\beta + \frac{\partial^2x^\beta}{\partial x'^\mu\partial x'^\nu}\,A_\beta .$$
The first term is the tensor law; the second, containing the second derivative of the coordinate map, is the obstruction. It vanishes exactly when the map is affine (constant Jacobian) — the Lorentz/Poincaré case.

**4. The antisymmetric part.** The obstruction $\frac{\partial^2x^\beta}{\partial x'^\mu\partial x'^\nu}A_\beta$ is symmetric in $\mu\nu$ (mixed partials commute for a $C^2$ coordinate map). Hence in $F'_{\mu\nu} = \partial'_\mu A'_\nu - \partial'_\nu A'_\mu$ the obstructions cancel and $F'_{\mu\nu} = \frac{\partial x^\alpha}{\partial x'^\mu}\frac{\partial x^\beta}{\partial x'^\nu}F_{\alpha\beta}$: a tensor under general coordinate transformations. Consequence: the Faraday tensor and hence the homogeneous Maxwell equations $\partial_{[\alpha}F_{\beta\gamma]} = 0$ are meaningful in any coordinates without a covariant derivative (Lecture 4 writes electrodynamics in geometric language). Unit 2 shows that $\nabla_\mu A_\nu - \nabla_\nu A_\mu = \partial_\mu A_\nu - \partial_\nu A_\mu$ because the Christoffel terms cancel the same way.

**Alternative valid approaches.** Any explicit boosted tensor works for the counterexample in part 1 (e.g. $T = \eta^{\mu\nu}$ itself has $\sum_\mu\eta^{\mu\mu} = 2$ in every inertial frame — *not* a counterexample; make sure the learner's example actually changes). For part 4, exterior-calculus language ($F = dA$, $d$ commutes with pullback) is a complete proof; accept it if the learner can translate it to components.

**Common gaps.** Using $\eta$ with the wrong sign in the trace (giving $+1$ for $u\cdot u$); choosing a counterexample whose diagonal sum happens to be invariant; forgetting that $\delta$ is invariant under *all* transformations while $\eta$ is not; asserting symmetry of the obstruction without saying why mixed partials commute.
