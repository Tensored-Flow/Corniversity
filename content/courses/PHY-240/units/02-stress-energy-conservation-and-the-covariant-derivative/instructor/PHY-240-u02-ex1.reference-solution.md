## Reference reasoning (instructor only)

**1. Christoffel symbols.** $g_{ij} = \mathrm{diag}(1, r^2, r^2\sin^2\theta)$, $g^{ij} = \mathrm{diag}(1, r^{-2}, r^{-2}\sin^{-2}\theta)$. Only $g_{\theta\theta}$ depends on $r$ and only $g_{\phi\phi}$ depends on $r$ and $\theta$. With the formula:
- $\Gamma^r{}_{\theta\theta} = \tfrac12g^{rr}(-\partial_rg_{\theta\theta}) = -r$ (metres).
- $\Gamma^r{}_{\phi\phi} = \tfrac12g^{rr}(-\partial_rg_{\phi\phi}) = -r\sin^2\theta$ (metres).
- $\Gamma^\theta{}_{r\theta} = \Gamma^\theta{}_{\theta r} = \tfrac12g^{\theta\theta}\partial_rg_{\theta\theta} = \tfrac12r^{-2}(2r) = 1/r$ ($\mathrm{m^{-1}}$).
- $\Gamma^\theta{}_{\phi\phi} = \tfrac12g^{\theta\theta}(-\partial_\theta g_{\phi\phi}) = -\tfrac12r^{-2}(2r^2\sin\theta\cos\theta) = -\sin\theta\cos\theta$ (dimensionless).
- $\Gamma^\phi{}_{r\phi} = \Gamma^\phi{}_{\phi r} = \tfrac12g^{\phi\phi}\partial_rg_{\phi\phi} = 1/r$ ($\mathrm{m^{-1}}$).
- $\Gamma^\phi{}_{\theta\phi} = \Gamma^\phi{}_{\phi\theta} = \tfrac12g^{\phi\phi}\partial_\theta g_{\phi\phi} = \cot\theta$ (dimensionless).
All others vanish. Units differ because $\theta,\phi$ are dimensionless and $r$ is a length: $\Gamma^k{}_{ij}$ has units $[x^k]/([x^i][x^j])$.

**2. Basis check.** $\mathbf x = r(\sin\theta\cos\phi,\sin\theta\sin\phi,\cos\theta)$, so $\mathbf e_r = (\sin\theta\cos\phi,\sin\theta\sin\phi,\cos\theta)$, $\mathbf e_\theta = r(\cos\theta\cos\phi,\cos\theta\sin\phi,-\sin\theta)$, $\mathbf e_\phi = r\sin\theta(-\sin\phi,\cos\phi,0)$. Then $\partial_\phi\mathbf e_\phi = -r\sin\theta(\cos\phi,\sin\phi,0)$. Decompose: $(\cos\phi,\sin\phi,0) = \sin\theta\,\mathbf e_r + (\cos\theta/r)\,\mathbf e_\theta$, so $\partial_\phi\mathbf e_\phi = -r\sin^2\theta\,\mathbf e_r - \sin\theta\cos\theta\,\mathbf e_\theta$, giving $\Gamma^r{}_{\phi\phi} = -r\sin^2\theta$ and $\Gamma^\theta{}_{\phi\phi} = -\sin\theta\cos\theta$. $\checkmark$ Also $\partial_r\mathbf e_\theta = \mathbf e_\theta/r$ gives $\Gamma^\theta{}_{r\theta} = 1/r$. $\checkmark$

**3. Divergence.** $\nabla_iV^i = \partial_iV^i + \Gamma^i{}_{ji}V^j$ with $\Gamma^i{}_{ri} = \Gamma^\theta{}_{r\theta} + \Gamma^\phi{}_{r\phi} = 2/r$, $\Gamma^i{}_{\theta i} = \Gamma^\phi{}_{\theta\phi} = \cot\theta$, $\Gamma^i{}_{\phi i} = 0$. So
$$\nabla_iV^i = \partial_rV^r + \frac2rV^r + \partial_\theta V^\theta + \cot\theta\,V^\theta + \partial_\phi V^\phi = \frac1{r^2}\partial_r(r^2V^r) + \frac1{\sin\theta}\partial_\theta(\sin\theta\,V^\theta) + \partial_\phi V^\phi .$$
With $\sqrt g = r^2\sin\theta$: $\partial_j\ln\sqrt g = (2/r,\cot\theta,0) = \Gamma^i{}_{ji}$, so this is $\frac{1}{\sqrt g}\partial_i(\sqrt g\,V^i)$. $\checkmark$ Orthonormal components $V^{\hat r} = V^r$, $V^{\hat\theta} = rV^\theta$, $V^{\hat\phi} = r\sin\theta V^\phi$ give the textbook form
$$\nabla\cdot\mathbf V = \frac1{r^2}\partial_r(r^2V^{\hat r}) + \frac1{r\sin\theta}\partial_\theta(\sin\theta\,V^{\hat\theta}) + \frac1{r\sin\theta}\partial_\phi V^{\hat\phi}.$$

**4. Laplacian.** $\nabla^2f = \nabla_i(g^{ij}\partial_jf)$ with $V^r = \partial_rf$, $V^\theta = r^{-2}\partial_\theta f$, $V^\phi = (r^2\sin^2\theta)^{-1}\partial_\phi f$:
$$\nabla^2f = \frac1{r^2}\partial_r(r^2\partial_rf) + \frac1{r^2\sin\theta}\partial_\theta(\sin\theta\,\partial_\theta f) + \frac1{r^2\sin^2\theta}\partial^2_\phi f .$$
Checks: $f = 1/r$: $r^2\partial_r(1/r) = -1$, constant, so $\nabla^2(1/r) = 0$ for $r\neq0$ — the Coulomb/Newton potential is harmonic. $f = r^2$: $\frac1{r^2}\partial_r(r^2\cdot2r) = 6$, and in Cartesian coordinates $\nabla^2(x^2+y^2+z^2) = 2+2+2 = 6$. $\checkmark$

**Alternative valid approaches.** Reading $\Gamma$ off the geodesic Lagrangian $L = \tfrac12 g_{ij}\dot x^i\dot x^j$ (Euler–Lagrange equations $\ddot x^k + \Gamma^k{}_{ij}\dot x^i\dot x^j = 0$) is the fastest route and should be welcomed; the exercise asks for the formula too. Using $\Gamma^i{}_{ji} = \partial_j\ln\sqrt g$ as a shortcut in part 3 is fine if it is verified.

**Common gaps.** Missing the factor $\tfrac12$ in $\Gamma^\theta{}_{\phi\phi}$ (giving $-2\sin\theta\cos\theta$); forgetting the symmetric partners; computing the divergence with orthonormal components but coordinate-basis $\Gamma$'s (mixing bases); checking $\nabla^2(1/r) = 0$ and stopping, when the $r^2$ check is the one that catches normalisation errors.
