# Mid-course synthesis: a hypothetical causal loop in two frames — reference reasoning

The outgoing line is $x=u(t-t_0)$ and Bob has $x=vt$, hence $t_B=ut_0/(u-v)=20t_0/11$, $x_B=18ct_0/11$. For the return, with $\Delta t=t_C-t_B$, $\Delta x=-x_B$, impose $\Delta x\prime=\gamma(\Delta x-v\Delta t)=-u\gamma(\Delta t-v\Delta x/c^2)$. Thus $(u-v)\Delta t=x_B(1-uv/c^2)$ and $t_C=u^2(1-v^2/c^2)t_0/(u-v)^2=76t_0/121<t_0$. The original emission A transforms to $t_A\prime=\gamma t_0$, $x_A\prime=-0.9\gamma ct_0$. B has $x_B\prime=0$ and $t_B\prime=t_B/\gamma$. C has $t_C\prime=\gamma t_C$, $x_C\prime=-0.9\gamma ct_C$. Numerically $\gamma=10/\sqrt{19}$; $t_C\prime-t_B\prime=\gamma(171/605)t_0>0$, so the reply is forward in Bob time. Each signal leg is spacelike because its speed magnitude in its sender frame is $2c$. Both event tables must agree under the same boost; diagrams may show Alice-time reversal on the return leg without reversing Bob's emission/reception order. The assumed device allows controllable superluminal transmission in both directions, immediate return and equal rules for inertial senders, with no preferred-frame chronology restriction. Spacelike correlations supply none of those communication abilities. This is a conditional inconsistency with ordinary causal ordering, not experimental evidence for a device.

## Assessment note

Accept any correct alternative derivation with equivalent stated conventions. A numerical check supports a calculation; it does not prove a general claim. Diagnose the first substantive gap, and do not equate help-assisted work with independent demonstration.
