# A pair in every causal class — reference reasoning

$A^2=-16$ is timelike: $\beta=3/5$ gives $\Delta x\prime=0$ and $\Delta ct\prime=4\,\mathrm m$. Simultaneity would require $\beta=5/3$, impossible. $B^2=16$ is spacelike: $\beta=3/5$ gives $\Delta ct\prime=0$ and $\Delta x\prime=4\,\mathrm m$; co-location would require $\beta=5/3$. Its time order can reverse. $C^2=0$ is a distinct future null vector; both attempted conditions require $\beta=1$, not an inertial boost. A and C retain positive time components because $\Delta ct-\beta\Delta x>0$ for $|\beta|<1$. The zero vector must be distinguished from C.
