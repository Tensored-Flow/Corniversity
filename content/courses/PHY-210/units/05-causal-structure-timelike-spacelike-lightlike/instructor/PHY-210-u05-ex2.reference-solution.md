# The relay cannot escape the cone — reference reasoning

For displacements $(c\Delta t_i,\mathbf x_i)$, $|\mathbf x_1+\mathbf x_2|\leq|\mathbf x_1|+|\mathbf x_2|\leq c(\Delta t_1+\Delta t_2)$. A nonzero future sum is null exactly when every nonzero summand is null and their spatial directions coincide. This follows from equality in both inequalities; a zero summand imposes no direction. In the example, the final norm is $-49+9+16=-24\,\mathrm m^2$, hence timelike. Each light segment has $ds^2=0$, so the broken light path has zero proper time, while an inertial massive clock joining the endpoints could accumulate $\sqrt{24}\,\mathrm m/c$. A photon has no rest clock; zero proper time does not define its rest frame.

## Assessment note

Accept any correct alternative derivation with equivalent stated conventions. A numerical check supports a calculation; it does not prove a general claim. Diagnose the first substantive gap, and do not equate help-assisted work with independent demonstration.
