# Two moving clocks and one simultaneity slice — reference reasoning

$\gamma=5/4$. At $\Delta t=0$, $\Delta x\prime=\gamma\Delta x=L\prime$, so $\Delta x=96\,\mathrm m$. The Lorentz time transformation gives $\Delta t\prime=-\gamma v\Delta x/c^2=-vL\prime/c^2=-72\,\mathrm m/c\simeq-0.24017\,\mu\mathrm s$ using exact $c$. Along either clock, $dx=vdt$, so $dt\prime=\gamma(1-v^2/c^2)dt=dt/\gamma=0.8dt$. Each advances $0.8\,\mu\mathrm s$. The offset compares two different worldlines at the same $S$ time; the rate follows successive events on one worldline.
