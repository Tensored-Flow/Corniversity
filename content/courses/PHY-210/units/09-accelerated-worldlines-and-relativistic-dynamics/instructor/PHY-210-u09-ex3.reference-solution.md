# A completely smooth reunion — reference reasoning

The half-period shift reverses $\theta$, so the two integrals of $\sinh\theta$ cancel and $x(T)=0$. Both endpoint rapidities vanish, so initial and final velocities are zero. Signed proper acceleration is $a_*(\tau)=(2\pi cq/T)\cos(2\pi\tau/T)$ and its magnitude is its absolute value. $t(T)=\int_0^T\cosh(q\sin(2\pi\tau/T))d\tau$. The integrand is at least one and is greater on a set of positive measure, so $t(T)>T$; it is at most $\cosh q$, proving the upper bound. The curve is smooth; all formulas used the constant Minkowski metric. It exhibits nonzero proper acceleration with zero spacetime curvature.
