# Classify four transformations — reference reasoning

P,T and PT preserve each diagonal square directly. The boost block $\begin{pmatrix}\cosh r&-\sinh r\\-\sinh r&\cosh r\end{pmatrix}$ preserves $\operatorname{diag}(-1,1)$ by $\cosh^2r-\sinh^2r=1$; transverse coordinates are fixed. P has $(\det,\text{time sign})=(-1,+)$, T has $(-1,-)$, B has $(+1,+)$, PT has $(+1,-)$. Only B is in the identity component; the path $B(sr)$,$s\in[0,1]$, proves connection. The discrete signs cannot change continuously since determinant cannot vanish and $|\Lambda^0{}_0|\geq1$. Multiplying $\Lambda^T\eta\Lambda=\eta$ on the left by $\eta$ gives $(\eta\Lambda^T\eta)\Lambda=I$. A nonzero translation sends 0 to $a\ne0$, while every linear matrix sends 0 to 0; affine/homogeneous coordinates can represent the larger Poincaré action.
