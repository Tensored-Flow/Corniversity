## Reference reasoning (instructor only)

**1. Model and loss.** $p = \sigma(z) = 1/(1 + e^{-z})$ gives $e^{-z} = (1 - p)/p$, so $z = \ln[p/(1 - p)] = \boldsymbol\theta^\top\mathbf{x}$: linear log-odds. Likelihood of $N$ independent trials: $\prod_i\sigma_i^{y_i}(1 - \sigma_i)^{1 - y_i}$ with $\sigma_i = \sigma(\boldsymbol\theta^\top\mathbf{x}_i)$. Negative log-likelihood (cross-entropy): $-\ell = -\sum_i[y_i\ln\sigma_i + (1 - y_i)\ln(1 - \sigma_i)]$. With $\sigma' = \sigma(1 - \sigma)$: $\partial(-\ell)/\partial\boldsymbol\theta = -\sum_i\big[y_i(1 - \sigma_i) - (1 - y_i)\sigma_i\big]\mathbf{x}_i = \sum_i(\sigma_i - y_i)\mathbf{x}_i$. (The Hessian $\sum_i\sigma_i(1 - \sigma_i)\mathbf{x}_i\mathbf{x}_i^\top$ is PSD, so the loss is convex.)

**2. Regularisation.** L2: the objective $-\ell + \frac{\beta}{2}\|\boldsymbol\theta\|^2$ has gradient $\sum_i(\sigma_i - y_i)\mathbf{x}_i + \beta\boldsymbol\theta$; the extra term is a restoring force proportional to the weight, so the optimum trades data fit against weight size and every weight shrinks towards zero, none exactly to zero unless the data term vanishes. L1: $\frac{\beta}{2}\sum|\theta_i|$ has subgradient $\pm\beta/2$ for $\theta_i \ne 0$ and the interval $[-\beta/2, \beta/2]$ at zero; a weight whose data gradient is smaller in magnitude than $\beta/2$ is held exactly at zero. Geometrically, the L1 constraint set is a diamond with corners on the axes, where level sets of the loss typically touch first; the L2 ball is round and touches off-axis. This is why L1 yields sparse decoders.

**3. Evaluation.** Correct: $27 + 21 = 48$ of $60$; accuracy $48/60 = 0.80 = 80\%$. Classes are balanced, so the majority-class baseline is $50\%$. A label-shuffle (permutation) control refits the whole pipeline on randomly permuted labels many times and reports the distribution of held-out accuracies; it measures what *this* pipeline achieves by chance on *this* data, including any optimism from the pipeline's own flexibility, which a fixed $50\%$ baseline cannot. (Sensitivity $0.90$ and specificity $0.70$ here; the asymmetry is worth reporting.)

**4. Pitfalls.** (a) Selecting the 50 most choice-correlated neurons using all trials uses the test trials' labels before they are "unseen"; the selected features are already tuned to them, so cross-validated accuracy is inflated. Selection must happen inside each fold. (b) With 90:10 imbalance, always predicting the majority gives 90%, so 80% is worse than useless; report balanced accuracy or compare with the 90% baseline. (c) Choosing $\beta$ by test accuracy makes the test set part of the fitting procedure; the reported number is then a training number. Use nested cross-validation or a separate validation split.

**5. Rewrite.** "The choice can be decoded from this population with 80% accuracy against a 50% baseline on held-out trials." The original claim (neurons drive the choice) needs an intervention: perturbing the activity of these neurons (in a real experiment, by means outside this course's scope) and observing whether the choice changes. Decoding cannot distinguish a cause from a correlate or a downstream copy.

**Alternative valid approaches.** Deriving the gradient from the exponential-family form; using the Lagrangian/constrained view of regularisation; using AUC or balanced accuracy in part 3. Accept $0.8$ and $80\%$.

**Common gaps.** Sign errors in the gradient; claiming L2 produces sparsity; reading $80\%$ without the baseline; treating (a) as harmless because "cross-validation was used"; keeping the causal sentence with a hedge word added.
