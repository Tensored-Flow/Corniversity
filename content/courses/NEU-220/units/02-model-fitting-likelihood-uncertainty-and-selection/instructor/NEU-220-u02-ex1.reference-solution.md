## Reference reasoning (instructor only)

**1. Least squares.** $S(\theta) = \sum_i(y_i - \theta x_i)^2$. $S'(\theta) = -2\sum_i x_i(y_i - \theta x_i) = 0 \Rightarrow \hat\theta_{LS} = \dfrac{\sum x_iy_i}{\sum x_i^2}$ (Tutorial 1's $\mathbf{x}^\top\mathbf{y}/\mathbf{x}^\top\mathbf{x}$). $S''(\theta) = 2\sum x_i^2 > 0$ whenever some $x_i \ne 0$, so this is the global minimum of a convex quadratic.

**2. Gaussian MLE.** $\ell(\theta, \sigma^2) = -\dfrac{N}{2}\ln(2\pi\sigma^2) - \dfrac{1}{2\sigma^2}\sum_i(y_i - \theta x_i)^2$. For fixed $\sigma^2$ the only $\theta$-dependence is through $S(\theta)$ with a negative coefficient, so $\hat\theta_{MLE} = \hat\theta_{LS}$ (Tutorial 2). $\partial\ell/\partial\sigma^2 = -\dfrac{N}{2\sigma^2} + \dfrac{S(\hat\theta)}{2\sigma^4} = 0 \Rightarrow \hat\sigma^2_{MLE} = S(\hat\theta)/N$. It is biased downward: with one fitted parameter $\mathbb{E}[S(\hat\theta)] = (N - 1)\sigma^2$, so $\mathbb{E}\hat\sigma^2_{MLE} = \sigma^2(N - 1)/N$; the unbiased estimator divides by $N - 1$.

**3. Heteroscedastic MLE.** $\ell = \text{const} - \sum_i\dfrac{(y_i - \theta x_i)^2}{2\sigma_i^2}$, so $\hat\theta_W = \dfrac{\sum_i x_iy_i/\sigma_i^2}{\sum_i x_i^2/\sigma_i^2}$: weighted least squares with weights $w_i = 1/\sigma_i^2$. It lets precise observations pull harder; ordinary least squares weighs every point equally, which is optimal only when the variances are equal.

**4. Numbers.** $\sum x_iy_i = 1(1.1) + 2(2.3) + 3(3.1) = 1.1 + 4.6 + 9.3 = 15.0$; $\sum x_i^2 = 14$; $\hat\theta = 15/14 = 1.0714$. Residuals: $1.1 - 1.0714 = 0.0286$; $2.3 - 2.1429 = 0.1571$; $3.1 - 3.2143 = -0.1143$. $S = 0.00082 + 0.02469 + 0.01306 = 0.03857$; $\hat\sigma^2_{MLE} = 0.03857/3 = 0.01286$ (unbiased: $0.01929$). Weighted with $\sigma_i = 0.1, 0.2, 0.3$ (weights $100, 25, 11.1$): numerator $100(1.1) + 25(4.6) + 11.11(9.3) = 110 + 115 + 103.3 = 328.3$; denominator $100(1) + 25(4) + 11.11(9) = 100 + 100 + 100 = 300$; $\hat\theta_W = 1.0944$. The estimate moved towards $1.1$, the slope implied by the first point alone, because that point is the most precise and carries weight 100 against 25 and 11.

**Alternative valid approaches.** Vector notation throughout; deriving the weighted estimator by rescaling $y_i/\sigma_i$, $x_i/\sigma_i$ and applying ordinary least squares. Accept $1.071$ and $1.094$.

**Common gaps.** Omitting the second-derivative check; claiming $\hat\sigma^2_{MLE}$ is unbiased; dividing the SSR by $N - 2$ (that is for a model with an intercept); forgetting to square the $\sigma_i$ in the weights.
