## Reference reasoning (instructor only)

**1. Decomposition.** Fix $x$ and write $f = f(x)$, $\hat f = \hat f(x)$, $\bar f = \mathbb{E}\hat f$ (expectation over training sets). Then $y - \hat f = \epsilon + (f - \bar f) + (\bar f - \hat f)$. Squaring:
$$(y - \hat f)^2 = \epsilon^2 + (f - \bar f)^2 + (\bar f - \hat f)^2 + 2\epsilon(f - \bar f) + 2\epsilon(\bar f - \hat f) + 2(f - \bar f)(\bar f - \hat f).$$
Expectations: $\mathbb{E}\epsilon^2 = \sigma^2$; $(f - \bar f)^2$ is deterministic, the squared bias; $\mathbb{E}(\bar f - \hat f)^2 = \text{Var}(\hat f)$. Cross terms: $\mathbb{E}[\epsilon(f - \bar f)] = (f - \bar f)\mathbb{E}\epsilon = 0$ (uses $\mathbb{E}\epsilon = 0$); $\mathbb{E}[\epsilon(\bar f - \hat f)] = \mathbb{E}\epsilon\cdot\mathbb{E}(\bar f - \hat f) = 0$ (uses independence of the new noise from the training set, then $\mathbb{E}\epsilon = 0$); $\mathbb{E}[(f - \bar f)(\bar f - \hat f)] = (f - \bar f)(\bar f - \mathbb{E}\hat f) = 0$. Hence $\mathbb{E}(y - \hat f)^2 = \sigma^2 + \text{Bias}^2 + \text{Var}$.

**2. Behaviour with polynomial order (Tutorial 5).** $\sigma^2$ is irreducible and constant. Low orders cannot represent the generating function, so bias is large; it falls as order increases. Higher orders fit the particular training noise, so $\hat f$ varies strongly between training sets and the variance rises. The test error is the sum and has an interior minimum; training error is computed on the data that determined $\hat f$, so the variance term appears there with the wrong sign, and it falls monotonically to zero at order $N - 1$.

**3. Bootstrap (Tutorial 3).** Procedure: from the $N$ observed pairs, draw $N$ with replacement, refit $\hat\theta$, repeat $B$ times (thousands), report the 2.5th and 97.5th percentiles. Assumptions: pairs independent and identically distributed; the empirical distribution a fair stand-in for the population (no important structure missing from the sample); $B$ large enough. Meaning of 95%: over repeated samples from the population, intervals built this way cover the true slope about 95% of the time; it is a property of the procedure, not a probability about this interval. The single interval $[1.05, 1.35]$ is consistent with the true $1.2$ and would have been consistent with $1.1$ or $1.3$ too; it does not confirm $1.2$, and in a real experiment the truth would not be available to check. Width: the standard error of the slope scales as $1/\sqrt{N}$ for independent sampling, so quadrupling $N$ halves the width (assuming the same noise level and $x$-distribution).

**4. Failure case.** Any of: a time series with slowly drifting residuals (serial correlation), where resampling pairs breaks the dependence and the intervals are too narrow; a single high-leverage point at extreme $x$ that is included in some resamples and not others, giving a bimodal bootstrap distribution and an interval that misstates the uncertainty; clustered trials (sessions, animals) treated as independent, which understates variability unless the clusters are resampled.

**Alternative valid approaches.** Proving the decomposition with conditional expectations; expressing variance scaling via the Fisher information. Accept "about half" for the width factor.

**Common gaps.** Dropping the cross term between bias and variance without saying why; saying the training error "also has a minimum"; reading 95% as a probability about the true value (the forbidden claim); forgetting the sample-size assumption behind the halving.
