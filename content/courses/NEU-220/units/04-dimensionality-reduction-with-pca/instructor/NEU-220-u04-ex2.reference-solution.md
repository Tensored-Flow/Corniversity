## Reference reasoning (instructor only)

Eigenvalues $5.0, 2.5, 1.0, 0.8, 0.4, 0.3$; total $10.0$.

**1. Variance explained.** Per component: $50\%, 25\%, 10\%, 8\%, 4\%, 3\%$. Cumulative: $50, 75, 85, 93, 97, 100\%$. The first $K$ to reach $\ge 90\%$ is $K = 4$.

**2. Reconstruction error.** With orthonormal components $\mathbf{w}_k$ and scores $s_k = \mathbf{x}^\top\mathbf{w}_k$, $\mathbf{x} = \sum_{k=1}^D s_k\mathbf{w}_k$ and $\hat{\mathbf{x}}_K = \sum_{k \le K}s_k\mathbf{w}_k$, so $\mathbf{x} - \hat{\mathbf{x}}_K = \sum_{k > K}s_k\mathbf{w}_k$ and $\|\mathbf{x} - \hat{\mathbf{x}}_K\|^2 = \sum_{k > K}s_k^2$ by orthonormality. Averaging over the (centred) data, $\overline{s_k^2} = \mathbf{w}_k^\top\boldsymbol\Sigma\mathbf{w}_k = \lambda_k$, so the mean squared reconstruction error is $\sum_{k > K}\lambda_k$. For $K = 2$: $1.0 + 0.8 + 0.4 + 0.3 = 2.5$ (25% of the total, matching 100% − 75%).

**3. The elbow.** Plot $\lambda_k$ against $k$; the elbow is where the curve flattens, i.e. where further components add little variance. Choosing $K$ there answers: how many linear dimensions reproduce the data to a given tolerance? It does not answer: which directions carry information about the stimulus, the choice or any other variable? PCA has no target variable and cannot address relevance.

**4. Counterexample (synthetic).** Six synthetic neurons receive a shared slow fluctuation (think arousal or a common input) that moves all of them together and accounts for the eigenvalue-5.0 direction; the stimulus modulates a particular weighted combination of the neurons with total variance 0.3 and is orthogonal to the shared direction. A two-component PCA keeps the shared fluctuation and the next largest direction and discards the stimulus direction entirely; a plot of the two scores coloured by stimulus shows no structure. Regressing the stimulus on all six scores (or decoding it) identifies the 0.3 direction; supervised reductions (e.g. targeted or demixed PCA) are built for this. The construction is stated as synthetic; it is a scenario, not an observation.

**5. Poisson scaling.** For Poisson-like counts, variance $\approx$ mean, so neurons with high rates have large count variance and dominate the covariance regardless of whether their variability is stimulus-related. Options, each to be stated: standardise each neuron to unit variance (correlation PCA); apply a variance-stabilising square-root transform; analyse trial-averaged responses so that trial-to-trial Poisson noise is reduced; or fit a model with explicit Poisson noise. None is neutral; the choice changes the components.

**Alternative valid approaches.** Writing the reconstruction error via the projection matrix $\mathbf{W}_K\mathbf{W}_K^\top$ and the trace identity $\text{tr}((I - \mathbf{W}_K\mathbf{W}_K^\top)\boldsymbol\Sigma) = \sum_{k > K}\lambda_k$. Accept 2.5 and 93%.

**Common gaps.** Cumulative percentages mis-added; reconstruction error given as the kept rather than discarded eigenvalues; the elbow read as "the important components"; a counterexample that is not orthogonal to the shared direction (then PCA partially captures the stimulus); no remedy offered for Poisson scaling.
