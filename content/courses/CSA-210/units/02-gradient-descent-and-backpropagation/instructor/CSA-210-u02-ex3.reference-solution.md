# Reverse versus forward differentiation — one complete answer

For a scalar output loss, seed its adjoint with one. The multivariable chain rule gives each earlier node's adjoint as the sum over its children of the child's adjoint times the local derivative along that edge. Reverse topological order makes those child adjoints available. One backward sweep therefore obtains derivatives for every parameter leaf. For the usual elementary operations, local derivative work is comparable to forward work, so the sweep costs a small constant multiple of the forward evaluation, with storage or recomputation trade-offs for intermediate values.

Forward mode seeds one input direction and propagates directional derivatives through the same graph. Obtaining a scalar loss's full gradient in N independent parameter directions normally needs N such sweeps (or the corresponding batched work). It is preferable for a requested Jacobian–vector product, which needs only one seeded direction, or for a mapping with few inputs and many outputs. Neither mode requires convexity; derivatives must exist or an explicit nonsmooth convention must be understood.
