## Reference reasoning (instructor only)

**1. Graph and forward pass.** Nodes: inputs $x_1,x_2$; parameters $w_1,w_2,b,v,c$; $z=w_1x_1+w_2x_2+b$; $h=\sigma(z)$; $\hat y=vh+c$; $L=\tfrac12(\hat y-y)^2$. A topological order is $(x_1,x_2,w_1,w_2,b,v,c,\;z,\;h,\;\hat y,\;L)$. Forward: $z=0.5\cdot1+1\cdot(-1)+0.5=0$; $h=\sigma(0)=0.5$; $\hat y=2\cdot0.5-0.5=0.5$; $L=\tfrac12(0.5-1.5)^2=\tfrac12(-1)^2=0.5$.

**2. Reverse sweep.** Local derivatives in brackets.

- $\bar{\hat y}=\partial L/\partial\hat y=\hat y-y=-1$.
- $\bar v=\bar{\hat y}\cdot[\partial\hat y/\partial v=h]=-1\cdot0.5=-0.5$.
- $\bar c=\bar{\hat y}\cdot[\partial\hat y/\partial c=1]=-1$.
- $\bar h=\bar{\hat y}\cdot[\partial\hat y/\partial h=v]=-1\cdot2=-2$.
- $\bar z=\bar h\cdot[\sigma'(z)=h(1-h)=0.25]=-0.5$.
- $\bar w_1=\bar z\cdot[x_1=1]=-0.5$.
- $\bar w_2=\bar z\cdot[x_2=-1]=0.5$.
- $\bar b=\bar z\cdot[1]=-0.5$.

**3. One step with $\eta=0.1$.** $\theta\leftarrow\theta-0.1\,\bar\theta$: $v=2+0.05=2.05$; $c=-0.5+0.1=-0.4$; $w_1=0.5+0.05=0.55$; $w_2=1-0.05=0.95$; $b=0.5+0.05=0.55$. New forward pass: $z=0.55-0.95+0.55=0.15$; $h=\sigma(0.15)=1/(1+e^{-0.15})=0.53743$; $\hat y=2.05\cdot0.53743-0.4=0.70173$; $L=\tfrac12(0.70173-1.5)^2=\tfrac12(0.79827)^2=0.3186$. The loss fell from $0.5$ to about $0.319$, consistent with the descent lemma (the step is small relative to the curvature here).

**4. Finite difference for $\partial L/\partial w_2$.** With $w_2=1.001$: $z=-0.001$, $h=\sigma(-0.001)=0.49975$, $\hat y=2\cdot0.49975-0.5=0.49950$, $L=\tfrac12(1.00050)^2=0.500500$. With $w_2=0.999$: $z=0.001$, $h=0.50025$, $\hat y=0.50050$, $L=\tfrac12(0.99950)^2=0.499500$. Central difference $(0.500500-0.499500)/0.002=0.5000$, matching $\bar w_2=0.5$ (the agreement is to about six places because a central difference of the smooth scalar loss has $O(\varepsilon^2)$ truncation error; the relevant error analysis concerns the full composed loss).

One backward sweep suffices because the adjoint recursion $\bar v_i=\sum_j\bar v_j\,\partial v_j/\partial v_i$ visits each edge once starting from the single scalar $L$, delivering $\partial L/\partial\theta$ for every leaf; forward mode seeds one leaf direction per sweep, so it would need five sweeps for the five parameters.

**Alternative valid approaches.** Writing the network as the composition $L=\ell\circ g\circ\sigma\circ f$ and applying the chain rule as a product of Jacobians (here all $1\times1$ or $1\times k$) is fully acceptable; the adjoint bookkeeping is the same computation in a different notation. Using $\tanh$-style derivations or symbolic differentiation of the full expression is acceptable if the numbers agree.

**Common gaps.** Forgetting $\sigma'(z)=h(1-h)$ and using $\sigma(z)$ instead (gives $\bar z=-1$); dropping the sign from $x_2=-1$ (gives $\bar w_2=-0.5$); updating with $+\eta\bar\theta$ (loss rises to about $0.73$); recomputing the loss with the old $h$; skipping the finite-difference check or using a one-sided difference and then puzzling over the small discrepancy.
