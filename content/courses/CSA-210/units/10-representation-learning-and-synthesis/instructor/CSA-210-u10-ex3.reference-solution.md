# An ELBO and a protocol boundary — reference reasoning

Bayes' rule gives log pθ(z|x) = log pθ(x, z) − log pθ(x). Therefore

KL(q || pθ(z|x)) = E_q[log q (z|x) − log pθ(x, z)] + log pθ(x).

Rearrange and factor pθ(x, z) = p (z) pθ(x|z):

log pθ(x) = E_q log pθ(x|z) − KL(q || p) + KL(q || pθ(z|x)).

The last KL is nonnegative, establishing the lower bound. For this finite-expression derivation, assume 0 < pθ(x) < ∞, appropriate absolute continuity of q with respect to the relevant prior/posterior densities, and finite expectations of the log ratios. Without those assumptions some expressions can be infinite and require additional care. A Gaussian observation likelihood with fixed variance makes the negative expected log-likelihood proportional to a squared error plus constants; MSE is not a universal likelihood.

Using test inputs to fit an encoder grants transductive access even if their labels are hidden. This may be a legitimate predeclared setting, but it differs from an inductive evaluation in which those inputs were never encountered. For the latter, give every fitted encoder only the same training inputs. Use a matched architecture for random features, declare the training budgets and transformations for fitted encoders, freeze them, and train the same probe class on training labels.

Select encoder and probe settings on validation under comparable search budgets, then freeze the full procedure before test evaluation. Include matched sample-size controls where bias changes the training subset, all predeclared seeds, uncertainty appropriate to independent examples or groups, and failure cases. Reconstruction and contrastive losses are not directly comparable downstream-quality metrics.

## Assessment note

Accept any correct alternative derivation with equivalent stated conventions. A numerical check supports a calculation; it does not prove a general claim. Diagnose the first substantive gap, and do not equate help-assisted work with independent demonstration.
