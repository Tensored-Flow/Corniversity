# Held-out evidence — one complete answer

If held-out observations are i.i.d. from the target distribution and independent of all fitting/selection decisions, then conditional on the fitted model, E[Rhat_T(fhat) | fhat] = R(fhat). For measurable ERM over a fixed class with finite expectations, E[inf_f Rhat_S(f)] ≤ inf_f E[Rhat_S(f)] = inf_f R(f) ≤ E[R(fhat)]. Thus training optimism is an expectation statement under those assumptions, not a samplewise law for arbitrary algorithms.

Selecting models by their test scores makes those scores part of the selection information and generally invalidates the independent held-out interpretation for the winner. Validation is the designated selection sample; freeze the procedure before evaluating independent confirmation data. Merely viewing an unchanged test result again is not adaptive selection.

For example, feature selection using all labels before random splitting exposes the eventual test labels to the representation. Performing that selection inside training folds closes this route. Other valid examples include future-derived features or unseparated entity groups, with their access mechanism stated.
