## Reference reasoning (instructor only)

**1. Standard error.** Let $K$ be the number of correct predictions. Under independence with fixed true accuracy $p$, $K\sim\mathrm{Binomial}(n,p)$, so $\mathbb E[\hat p]=p$ and $\operatorname{Var}(\hat p)=\operatorname{Var}(K)/n^2=p(1-p)/n$. Hence $\mathrm{SE}(\hat p)=\sqrt{p(1-p)/n}$. At $p=0.9$, $n=200$: $\sqrt{0.09/200}=\sqrt{4.5\times10^{-4}}=0.02121\approx0.0212$. Using the normal approximation, a 95% interval is $0.90\pm1.96\times0.0212=0.90\pm0.042$, i.e. about $[0.86,0.94]$. (Plugging $\hat p$ for $p$ is itself an approximation; a learner who uses a Wilson interval should be accepted.)

**2. Two models.** The gap 0.015 is smaller than the single-model standard error of about 0.0212. That comparison is a rough warning against treating the larger accuracy as decisive, not a complete test of a paired difference. The independent-estimate calculation of roughly 0.03 is not automatically valid because both predictions were measured on the same items; their covariance can be positive, zero or negative.

Let b count A-correct/B-wrong cases and c count B-correct/A-wrong cases. Here c−b = 3, but b+c is unknown. For D = B_correct − A_correct, estimate its mean and variance from these paired outcomes; the standard error of the mean uses that paired variance divided by n. Under an exchangeable equal-accuracy null for discordant cases, an exact conditional test treats c among b+c disagreements as Binomial(b+c, 1/2). For example b=4, c=7 gives only 7 of 11 discordant outcomes favouring B, which is weak evidence. A paired analysis uses the actual joint data; it does not have a universally smaller standard error regardless of the covariance.

**3. Sample size.** Require $\sqrt{0.9\times0.1/n}\le0.005\iff 0.09/n\le2.5\times10^{-5}\iff n\ge0.09/2.5\times10^{-5}=3600$. A test set of 3,600 items is needed for a standard error of half a percentage point at accuracy 0.9.

**4. Seeds.** A different seed changes the initial weights, the order of mini-batches, dropout masks and augmentation draws, so gradient descent follows a different path to a different function, which makes different errors on the fixed test items. A report must give the number of seeds, the mean and spread (standard deviation or range) across them, and the test-set standard error, and must never present the best seed's number as the result.

**Alternative valid approaches.** Exact binomial or Wilson intervals for part 1; a bootstrap over test items for part 2 (acceptable if the pairing is preserved by resampling items, not predictions); solving part 3 with $p=\hat p=0.9$ or with the conservative $p=0.5$ (which gives $n\ge10{,}000$; accept if the learner says why).

**Common gaps.** Dividing the binomial variance by $n$ instead of $n^2$ (giving $\sqrt{18}$-sized nonsense or $0.3$); reporting $0.0045$ (the variance, not its square root); concluding the second model is better because $0.915>0.90$; forgetting that the same test items make the comparison paired.
