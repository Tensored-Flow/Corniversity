# Count heads and quadratic storage — reference reasoning

Four 64×64 matrices give 16,384 weights. The four bias vectors add 256 parameters, for a total of 16,640.

A score tensor has axes (batch, head, query, key). At length 2048 it contains 2×8×2048² = 67,108,864 float32 values: 268,435,456 bytes, or 256 MiB using 2²⁰ bytes per MiB. Length 4096 quadruples this to 268,435,456 values and 1,073,741,824 bytes = 1024 MiB = 1 GiB.

This counts only the specified score tensor. It excludes projections, other layers, gradients, optimiser state and other temporaries. Fused or streaming implementations may avoid retaining this entire intermediate. A different head-width convention changes the dimensions. Distinguish operation count from stored intermediate memory.
