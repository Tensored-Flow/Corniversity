# Prove when order disappears — reference reasoning

Let P be a permutation matrix. With shared projections and no positional or mask structure, Q′ = PQ, K′ = PK and V′ = PV. Thus S′ = PSPᵀ. Permuting rows and columns simply reorders the row-softmax probabilities, so A′ = PAPᵀ. Therefore O′ = A′V′ = PAPᵀPV = PO.

Mean pooling is (1/n)1ᵀO. Since 1ᵀP = 1ᵀ, the pooled output is unchanged. AB and BA have the same token multiset, so this deterministic classifier receives the same representation for both and cannot assign their opposite labels correctly.

With positional vectors attached to fixed positions, permuting tokens while keeping those positions fixed no longer gives the same projected input as PX. With a fixed causal mask, the mask does not generally transform as PMPᵀ under an arbitrary permutation, so the masked-score identity fails. Other order-sensitive components can also violate the premises. This is a scoped impossibility result, not a statement that all transformers ignore order.

## Assessment note

Accept any correct alternative derivation with equivalent stated conventions. A numerical check supports a calculation; it does not prove a general claim. Diagnose the first substantive gap, and do not equate help-assisted work with independent demonstration.
