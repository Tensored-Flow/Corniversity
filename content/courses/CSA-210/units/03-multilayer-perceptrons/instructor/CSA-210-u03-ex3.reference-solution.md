# Represent XOR and disprove affine separation — reference reasoning

Use h1=ReLU(x1+x2), h2=ReLU(x1+x2−1), f=h1−2h2. Scores at sums 0,1,2 are 0,1,0. The architecture has 4+2+2+1=9 parameters, though this explicit representation ties/choses values. For affine g=w1x1+w2x2+b, class 0 at (0,0) requires b≤0; positives give w1+b>0, w2+b>0, hence w1+w2+2b>0. Then w1+w2+b>−b≥0, contradicting class 0 at (1,1). It is representational impossibility for this threshold convention, not a claim about optimisation or other feature maps.
