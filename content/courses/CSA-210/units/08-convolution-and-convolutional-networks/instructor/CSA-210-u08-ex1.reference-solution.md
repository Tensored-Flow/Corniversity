# An operator and its transpose — reference reasoning

C=[[1,2,0,0],[0,1,2,0],[0,0,1,2]]. y=(0,5,11). dx=Cᵀg=(1,0,−1,6). dw=(1×2−2×(−1)+3×3,1×(−1)−2×3+3×4)=(13,5). g·y=0−10+33=23; dx·x=2+0−3+24=23. C maps R4→R3 and has a nonzero nullspace, so it is not invertible on all R4; Cᵀ maps gradients by the chain rule. Transposition alone is not reconstruction.
