## Outline: Deep linear networks: learning dynamics through the SVD

This unit is **outlined, not yet prepared**. It will be written from W1D2 Tutorial 3 (Deep linear neural networks) of the Neuromatch Deep Learning ebook, with Tutorial 2 (Learning Hyperparameters) as a preview of hyperparameter choice (content CC BY 4.0), cited by tutorial page and section.

**Scope.** A network with no nonlinearities computes a single matrix, yet gradient descent on its factors behaves unlike gradient descent on that matrix: learning proceeds in stages, one singular direction at a time, with speed set by the singular values of the input–output correlation. The unit derives the gradient-flow equations for a two-layer linear network, decouples them with the SVD, and reads off the stage-like learning curves the tutorial shows on a hierarchical "tree" dataset. It then treats representational similarity analysis as a way of comparing internal representations across networks and layers, and the tutorial's illusory-correlation demonstration: a network that transiently asserts a correlation absent from the data, which is an observation about training dynamics and not about the data.

**What preparation will add.** A full lesson with the SVD derivation written out (the learner's linear algebra makes this the natural centrepiece), original exercises (the decoupled equations for one singular mode and their time to learn as a function of the singular value; an RSA matrix computed by hand for a tiny dataset; an argument for why a shallow linear network does not show stage-like learning), instructor reference reasoning, an exit check and the unit's common misconceptions ("a linear network is just linear regression, so its training is uninteresting"). Until then the reading above is accurate and the tutor can discuss the material, but there is no assessed work for this unit.
